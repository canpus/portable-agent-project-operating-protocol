# 工具执行、验证与产物检查

## 触发

运行命令/工具/构建/测试；生成或转换代码以外的文档、表格、PDF、图片、音视频或其他交付物。

1. 使用宿主真实提供的语义等价能力；工具缺失时寻找项目范围内替代，仍不可行则说明限制，不假装执行。
2. 命令前确认工作目录、目标、输入和可能副作用。批量/递归操作先核对解析后的绝对边界；不把未转义的不可信文本拼进命令。
3. 每次失败读取真实错误，形成新假设后改变输入/方法；输入、环境和假设均未变化时不机械重试。
4. 验证覆盖本次最可能出错的成功、失败和边界行为。运行项目规定检查；通过后只有新修改、失败或未解决疑点才扩大或重复。
5. 区分命令退出成功、文件产生、格式可打开和业务行为正确。检查实际输出，不由工具调用成功推断业务成功。
6. 文档/表格/幻灯片/PDF 做结构和必要视觉检查；图片/音视频核对格式、尺寸/时长及关键内容。无法检查的部分明确写未验证。
7. 正式输出和诊断/临时文件分开；保留回到原始输入和原始工具输出复查的路径，不把临时调试结果冒充交付物。
8. 完成前检查目标路径、差异、文件清单、必要哈希/元数据和未验证项；测试失败和工具限制如实交付。
